# NextCar — Frontend Assignment

An interactive animated car showcase built with Next.js, React, TypeScript, and Tailwind CSS.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- next-themes

## Features

- Multi-stage car and timeline animations
- Interactive timeline experience
- Dark / Light theme toggle
- Responsive component-based UI

## Getting Started

```bash
npm install
npm run dev
